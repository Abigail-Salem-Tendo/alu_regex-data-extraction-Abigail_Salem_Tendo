# Regex Data Extraction Project
## Overview

This project is a simple menu-driven python program that extracts different types of information from text using regular expression (regex).
This project can find and display:

* Email Addresses
* URLs
* Phone numbers
* Hashtags
* Times (12-hour and 24-hour format)

The Program can process sample text from a file and can handle file errors.

## Features

1. Menu-driven CLI interface
   * Extract all data at once
   * Extract a single data type at a time


2. Support for multiple data formats
    * Emails, URLS, phone numbers, hashtags, times


3. Error Handling
    * Detects invalid file paths
    * Handles invalid menu choices


4. Sample data included
    * Example text to simulate how it works
    * Invalid examples to test regex accuracy

## Installation
1. You should have Python3 installed.


2. Clone this repository:

```
https://github.com/Abigail-Salem-Tendo/alu_regex-data-extraction-Abigail_Salem_Tendo.git
```

3. Navigate to the project folder:

```angular2html
cd alu_regex-data-extraction-Abigail_Salem_Tendo
```

## Usage
1. Run the program:
```angular2html
python3 regex_extract.py
```
2. Follow the menu prompts to:
    * Extract all the data at once
    * Extract one data type at a time
    * Exit the program


3. Optional: You can edit or create a `sample_text.txt` file in the same folder to provide your own text to extraction.
